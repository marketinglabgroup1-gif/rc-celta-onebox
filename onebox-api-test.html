Overview Integration flow

ONEBOX API integration

Three endpoints power the RC Celta ticketing flow on this channel: obtain a bearer token, fetch the list of available matches, and read per-section seat availability for one match. Every example below was captured against the live sandbox; secrets are redacted so this page is safe to share.

Base URL  https://api.oneboxtds.net
Auth  OAuth 2.0 client credentials — the access token is short-lived (12 h) and must be sent as Authorization: Bearer <token> on every catalog call.

Integration flow

Each session, the client obtains a token, then calls the catalog endpoints with it. Tokens last 43200 s (12 h) — cache them and refresh proactively before expiry. 

  ┌─────────────┐    POST /oauth/token   ┌──────────────┐
  │   Client    │  ───────────────────►  │   ONEBOX     │
  │  (RC Celta) │  ◄───  access_token    │   Auth       │
  └─────────────┘                        └──────────────┘
        │
        │   GET /catalog-api/v1/sessions                  (Bearer token)
        ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  list of matches  ──►  pick one  ──►  GET /sessions/:id/...  │

  └──────────────────────────────────────────────────────────────┘

Authentication

POST /oauth/token

Exchanges client credentials for a short-lived bearer token. The response also returns the granted scope — the channel must include api-catalog-all for the calls below to work.

ParameterTypeDescription
grant_typerequiredstringAlways client_credentials.
channel_idrequiredintegerSales channel identifier (RC Celta uses 2287).
client_idrequiredstringProvided by ONEBOX — seller-channel-client.
client_secretrequiredstringChannel secret. Store in .env, never commit.

Request

cURL
curl -X POST https://api.oneboxtds.net/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  --data-urlencode "grant_type=client_credentials" \
  --data-urlencode "channel_id=2287" \
  --data-urlencode "client_id=seller-channel-client" \
  --data-urlencode "client_secret=$ONEBOX_CLIENT_SECRET"
Headers
Content-Typeapplication/x-www-form-urlencoded
Body
grant_type=client_credentials
channel_id=2287
client_id=seller-channel-client
client_secret=••••••••••••••••••••••••••••••••

List matches

GET /catalog-api/v1/sessions

Returns the paginated list of sessions (matches) on the channel. Each item bundles the event, venue, date window, current price range, and a high-level availability summary — useful for the match listing screen without a second round-trip.

Query parameterTypeDescription
limitintegerPage size, default 100.
offsetintegerZero-based offset for pagination.

Request

cURL
curl https://api.oneboxtds.net/catalog-api/v1/sessions \

Seat availability for one match

GET /catalog-api/v1/sessions/{sessionId}/availability

Returns a fine-grained breakdown of seat availability for a single session: a global total, per price type (e.g. VIP, PISO 1) totals, and per-sector (grada) totals keyed by stadium section. Drives the seat-map and "tickets left" counters.

Path parameterTypeDescription
sessionIdrequiredintegerSession id from the /sessions response.
